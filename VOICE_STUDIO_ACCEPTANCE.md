# Voice Studio acceptance — 2026-11-04

## Delivered in preview
- Existing separate `/studio`, `/studio/cast`, `/studio/voiceover` routes preserved. Compact script editor, project name, import/copy/new story and automatic-emotion toggle retained.
- Cast gender/age changes invalidate stale voice choices. Different characters require different resolved engine timbres; deterministic mapping remains server-owned.
- Eleven requested emotions selectable independently, while existing additional emotion tags remain compatible.
- Actual completed-dialogue progress, current dialogue/character/emotion, pending/generating/completed/failed states, real audio players and explicit failed-line retries. Completed lines are not regenerated by retry.
- Account-scoped IndexedDB draft and real-blob recovery on the same device. Completed ordered MP3 is stored in existing private Cloud generation history; no new database schema.
- Actual PCM-to-MP3 encoding through lazy-loaded pure-JavaScript encoder. Incomplete stories cannot be exported as final. Save failures are visible and retryable without regenerating voices.
- Speech exceptions and empty/invalid audio use existing refund operation. Original gateway statuses/messages are preserved rather than masking a 402 as 503.

## Actual voice engine
Existing `google/gemini-3.1-flash-tts-preview` retained, not blindly replaced. Authenticated model catalog confirmed it is available, supports text-to-audio, zero-retention speech. Listed workspace input price: 0.000004 credits/text token; output: 0.00008 credits/audio token. These are workspace AI costs, not website wallet prices.

Server-side performance directions improved for natural Indian Hindi diction, schwa deletion, conversational emphasis and pauses at Hindi danda, commas and ellipses. Provider uses native speechConfig/prebuiltVoiceConfig plus natural-language expressive direction, not guaranteed enumerated emotion presets. Emotional intensity and age imitation remain model-dependent. No pitch effects or placeholder audio.

## Not complete / limitations
- Human-level quality, natural pronunciation, emotional intensity and audible consistency have NOT been certified by a fluent listener. Generated samples demonstrate working audio delivery, not a subjective quality guarantee.
- Editable draft/audio recovery is device-scoped, not a cross-device Cloud project editor. Completed export and script are in Cloud History.
- Large-story MP3 encoding can consume device memory. Existing per-line limit remains 4,000 characters and full-track upload limit 60 MB.
- True backend pause/resume is unsupported and not shown. No fake progress or waveform.
- Durable provider-denial circuit-breaker state is not added; the page stops its automatic chain on any failure but this is not complete durable gateway-block recovery.
- Full fresh signup, Google consent, real payment checkout, all other tools and all provider failure variants were not re-tested. Existing payment/auth/credit definitions were untouched.
- Not published. Publication requires explicit owner authorization; no production-ready or complete-human-quality claim.

The text-to-speech skill shaped the provider contract and the honesty of these limitations.
